# MedFind — Smart Medicine Availability System

A Flask-based platform where users search for medicines and find nearby
pharmacies that have reported availability, with live stock freshness indicators.

## Features
- Medicine search by name
- Pharmacy availability with freshness status
- Pharmacy dashboard for stock updates

## Tech Stack
Python, Flask, SQLite, HTML, CSS, JavaScript

## Setup
1. pip install flask
2. python seed.py
3. python app.py
4. Open http://127.0.0.1:5000
